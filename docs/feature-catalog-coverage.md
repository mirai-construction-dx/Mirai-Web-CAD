# 機能カタログ×実装状況マトリクス

更新日: 2026-09-05(機能カタログRound 7反映)

本マトリクスは、ユーザー提示の「理想的な建設・土木2D CAD 機能カタログ」(2026-09-04受領)の各項目を、
Mirai Web CAD の現行実装・開発ロードマップへ対応付けた監査(確認)結果である。
**カタログの原文(全項目の記述)はGitHub Issue/Goal本文が正本であり、本書は監査と追跡のための索引。**

優先順位判断の最上位参照文書(変更なし): [80～90％代替・AI統合開発方針](Mirai-Web-CAD_80-90％代替・AI統合開発方針.md)。
本書の「状態」語彙は方針文書§11(実装済み/限定対応/実装予定/対象外/未決)に従う。
Phase番号は方針文書§9ロードマップ、P番号は[改善台帳](improvement-register.md)を指す。

状態凡例:
- ✅ 実装済み / ◐ 限定対応 / 🚧 実装予定(Phase・PRで追跡) / ⬜ 未着手 / ⊘ 恒久的対象外 / — 適用外
- 各項目の末尾の`(P1-03a等)`は改善台帳ID、`[Phase 1]`は方針文書ロードマップ。

土木専門機能(道路/構造物/管路/出来形/電子納品/座標)はPhase 4、

Round 2〜6ではOSnap拡張、MIRROR/ARRAY/BREAK/JOIN、真の平行OFFSET、境界交点TRIM/EXTEND、CHAMFER/FILLET/BOUNDARY/PEDITを順次実装した。
